La neurona artificial — El perceptrón

Una red neuronal artificial está formada por unidades elementales llamadas neuronas artificiales o perceptrones. Cada neurona es una función matemática que toma múltiples entradas, las combina de forma lineal y aplica una transformación no lineal para producir una salida.

La inspiración viene de la neurona biológica: las dendritas reciben señales, el soma las integra y el axón transmite la respuesta. La neurona artificial lo traduce en álgebra lineal.

z = w₁·x₁ + w₂·x₂ + w₃·x₃ + b = w·x + b
ŷ = f(z) z = combinación lineal (preactivación) · ŷ = salida de la neurona · f = función de activación

Entradas (x)

Los valores de cada feature: descriptores moleculares, bits de fingerprint, píxeles de imagen, etc.

Pesos (w) y sesgo (b)

Los parámetros aprendibles. El peso controla cuánto importa cada entrada. El sesgo desplaza la activación.

Función de activación f

Introduce no linealidad. Sin ella, apilar capas lineales equivale a una sola capa lineal — el modelo no ganaría expresividad.

💡

Una sola neurona puede resolver problemas linealmente separables (como regresión logística). La potencia real viene de combinar muchas neuronas en capas — cada una aprende una característica distinta del espacio de entrada.

Funciones de activación

Sin funciones de activación no lineales, una red de N capas es equivalente a una sola transformación lineal — no importa cuántas capas apiles. Las funciones de activación rompen esa linealidad y permiten que la red aprenda relaciones complejas.

Sigmoide  σ(z)
σ(z) = 1 / (1 + e⁻ᶻ)

Salida en [0,1]. Ideal para la capa de salida de clasificación binaria (interpreta la salida como probabilidad). Problema: gradiente se aplana en extremos → gradiente desvaneciente en redes profundas.

ReLU
f(z) = max(0, z)

La activación más usada en capas ocultas. Computacionalmente eficiente. Evita el gradiente desvaneciente en la zona positiva. Problema: "neuronas muertas" si z siempre es negativo.

Tanh
f(z) = (eᶻ − e⁻ᶻ) / (eᶻ + e⁻ᶻ)

Salida en [−1,1], centrada en cero. Ventaja sobre sigmoide: gradientes más grandes cerca del origen. Aún sufre gradiente desvaneciente en extremos. Buena para RNNs.

Softmax
σ(zᵢ) = eᶻⁱ / Σⱼ eᶻʲ

Convierte un vector de logits en distribución de probabilidades que suma 1.0. Solo para la capa de salida en clasificación multiclase. Nunca usarla en capas ocultas.

Arquitectura — Capas y conexiones

Una red neuronal feedforward (completamente conectada o densa) organiza las neuronas en capas. Cada neurona de una capa está conectada a todas las neuronas de la siguiente. La información fluye en una sola dirección: de la entrada a la salida.

Capa de entrada

Una neurona por feature. Sin función de activación — simplemente pasa los valores. Con descriptores Mordred: ~300 neuronas. Con Morgan ECFP4: 2048 neuronas.

Capas ocultas

Aprenden representaciones jerárquicas. Las primeras capas detectan patrones simples; las profundas detectan patrones complejos. Cada capa transforma el espacio de features.

Capa de salida

Produce la predicción final. 1 neurona + sigmoide para clasificación binaria. N neuronas + softmax para multiclase. 1 neurona lineal para regresión de pIC50.

Forward pass — Predicción

El forward pass (o propagación hacia adelante) es el proceso de calcular la predicción de la red dada una entrada. Se ejecuta capa por capa desde la entrada hasta la salida.

h⁽¹⁾ = f(W⁽¹⁾·x + b⁽¹⁾)
h⁽²⁾ = f(W⁽²⁾·h⁽¹⁾ + b⁽²⁾)
ŷ = f_out(W⁽ᴸ⁾·h⁽ᴸ⁻¹⁾ + b⁽ᴸ⁾) W⁽ˡ⁾ = matriz de pesos de la capa l · h⁽ˡ⁾ = activaciones de la capa l · L = número de capas
  1. Entrada al batch

    Se toman B moléculas (batch), cada una representada como vector de n features. Resultado: matriz X de forma [B × n_features].

  2. Capa lineal

    Se calcula z = X·Wᵀ + b. La multiplicación de matrices combina todas las entradas con todos los pesos simultáneamente. Resultado: z de forma [B × n_neuronas].

  3. Batch Normalization (opcional)

    Normaliza z a media 0 y varianza 1 dentro del batch. Luego escala y desplaza con parámetros aprendibles γ y β. Estabiliza los gradientes.

  4. Función de activación

    Se aplica f(z) elemento a elemento. Para capas ocultas: ReLU. Para la capa de salida: sigmoide (binaria) o softmax (multiclase).

  5. Repetir para cada capa

    La salida h de cada capa se convierte en la entrada de la siguiente. Al final, ŷ es la predicción final.

def forward_manual(X, pesos, sesgos, activaciones):
    """Ilustración del forward pass capa por capa."""
    h = X
    for W, b, f in zip(pesos, sesgos, activaciones):
        z = h @ W.T + b          # combinación lineal
        h = f(z)                  # función de activación
    return h                      # ŷ = predicción final

Función de pérdida (Loss)

La función de pérdida mide qué tan lejos está la predicción ŷ del valor real y. El objetivo del entrenamiento es minimizar esta función ajustando los pesos w.

Binary Cross-Entropy (BCE)

L = −[y·log(ŷ) + (1−y)·log(1−ŷ)]

Para clasificación binaria (activo/inactivo). Penaliza fuertemente cuando el modelo predice con alta confianza la clase incorrecta. Requiere sigmoide en la capa de salida.

MSE — Error Cuadrático Medio

L = (1/n)·Σ(yᵢ − ŷᵢ)²

Para regresión continua (predicción de pIC50). Penaliza los errores grandes cuadráticamente. Sensible a outliers — considerar MAE o Huber si hay muchos.

⚠️

Con clases desbalanceadas (10% activos, 90% inactivos), la BCE estándar tiene sesgo hacia la clase mayoritaria. Solución: usar pos_weight en PyTorch o class_weight='balanced' — equivalente al scale_pos_weight de XGBoost.

import torch.nn as nn

# Clasificación binaria con desbalance
n_inactivos = 850; n_activos = 150
pos_weight = torch.tensor([n_inactivos / n_activos])  # ≈ 5.67
criterion = nn.BCEWithLogitsLoss(pos_weight=pos_weight)

# BCEWithLogitsLoss combina sigmoide + BCE — más estable numéricamente
loss = criterion(logits, y_true.float())

Backpropagation y gradiente

La backpropagación (retropropagación del error) es el algoritmo que calcula cómo cada peso contribuye al error total. Usa la regla de la cadena del cálculo diferencial para propagar el gradiente de la pérdida desde la capa de salida hacia la entrada.

¿Por qué la regla de la cadena?

La red es una composición de funciones: ŷ = fₗ(fₗ₋₁(...f₁(x)...)). Para saber cómo cambia la pérdida L al cambiar un peso w en la capa k, necesitamos la derivada parcial ∂L/∂w, que se calcula descomponiendo la derivada como una cadena:

∂L/∂W⁽ᵏ⁾ = (∂L/∂h⁽ᴸ⁾) · (∂h⁽ᴸ⁾/∂h⁽ᴸ⁻¹⁾) · ... · (∂h⁽ᵏ⁺¹⁾/∂W⁽ᵏ⁾) Regla de la cadena aplicada capa por capa — se propaga el "error" de la salida hacia la entrada
  1. Calcular el error en la salida

    δ⁽ᴸ⁾ = ∂L/∂z⁽ᴸ⁾ — el gradiente de la pérdida respecto a la preactivación de la última capa.

  2. Propagar hacia atrás

    Para cada capa k = L-1, L-2, ..., 1: δ⁽ᵏ⁾ = (W⁽ᵏ⁺¹⁾)ᵀ · δ⁽ᵏ⁺¹⁾ ⊙ f'(z⁽ᵏ⁾). ⊙ = producto elemento a elemento.

  3. Calcular gradientes de los pesos

    ∂L/∂W⁽ᵏ⁾ = δ⁽ᵏ⁾ · (h⁽ᵏ⁻¹⁾)ᵀ y ∂L/∂b⁽ᵏ⁾ = δ⁽ᵏ⁾

  4. Actualizar los pesos

    W⁽ᵏ⁾ ← W⁽ᵏ⁾ − η·∂L/∂W⁽ᵏ⁾. El optimizador decide exactamente cómo hacer esta actualización.

✅

En PyTorch, loss.backward() ejecuta automáticamente toda la backpropagación usando autograd — el grafo computacional se construye durante el forward pass y se usa para calcular todos los gradientes. No necesitas implementarla manualmente.

El problema del gradiente desvaneciente

En redes profundas con activaciones sigmoide o tanh, el gradiente se multiplica por un número pequeño (la derivada de la activación en los extremos ≈ 0) en cada capa. Después de muchas capas, el gradiente se vuelve tan pequeño que los pesos de las primeras capas prácticamente no se actualizan.

Problema: gradiente desvaneciente

Con sigmoide: σ'(z) ≤ 0.25 siempre. Multiplicar 0.25 por sí mismo L veces → 0.25^L → 0 muy rápido. Las primeras capas no aprenden.

Solución: ReLU + Batch Norm

ReLU'(z) = 1 para z > 0 — el gradiente no se atenúa. Batch Normalization mantiene las activaciones en un rango estable entre capas.

6b

Ajuste de pesos — ¿Cómo aprende la red?

Una vez calculados los gradientes con backpropagation, el optimizador los usa para modificar cada peso en la dirección que reduce la pérdida. Este proceso se repite para cada batch y cada época hasta que el modelo converge.

La intuición geométrica

Imagina la pérdida L como una superficie montañosa en el espacio de todos los pesos. El gradiente apunta hacia la dirección de mayor subida. Para minimizar L, nos movemos en la dirección opuesta al gradiente — descendemos la montaña paso a paso.

w_nuevo = w_actual − η · ∂L/∂w η = learning rate (tamaño del paso) · ∂L/∂w = gradiente (dirección de subida) · El signo − = vamos hacia abajo

Haz clic para reiniciar la animación. La bola desciende siguiendo el gradiente.

El papel del learning rate η

η demasiado grande

El paso es tan grande que salta por encima del mínimo y diverge. La pérdida oscila o sube. El entrenamiento es inestable.

η adecuado

Converge suavemente hacia el mínimo. Cada actualización reduce la pérdida de forma estable. Típico: 1e-3 con Adam.

η demasiado pequeño

El paso es tan pequeño que tarda muchísimas épocas en converger, o queda atrapado en un mínimo local subóptimo.

Ejemplo numérico paso a paso

Supón una red con un solo peso w = 2.0 y una pérdida L = w². El gradiente es ∂L/∂w = 2w. Con η = 0.1:

El ciclo completo epoch por epoch

  1. Inicialización de pesos

    Se inicializan con valores aleatorios pequeños (Xavier/He initialization). Iniciar con ceros no funciona: todas las neuronas aprenderían lo mismo (simetría).

  2. Forward pass por batch

    Se toma un minibatch de B moléculas. Se calcula ŷ = f(x; w) y la pérdida L(ŷ, y). PyTorch registra cada operación en el grafo computacional.

  3. Backpropagation

    loss.backward() recorre el grafo al revés y calcula ∂L/∂w para cada parámetro. Los gradientes se acumulan en param.grad.

  4. Actualización de pesos

    optimizer.step() aplica la regla de actualización (SGD, Adam, etc.) usando los gradientes acumulados. Cada peso se desplaza un paso hacia el mínimo.

  5. Limpiar gradientes

    optimizer.zero_grad() reinicia los gradientes a cero antes del siguiente batch. Si no se hace, los gradientes se acumulan incorrectamente.

  6. Repetir para todos los batches (= 1 época)

    Una época = una pasada completa por todos los datos de entrenamiento. Típicamente se necesitan 50–200 épocas para que la red converja.

# El orden importa — siempre el mismo:
for X_batch, y_batch in train_loader:

    optimizer.zero_grad()            # 1. Limpiar gradientes anteriores

    y_pred = modelo(X_batch)         # 2. Forward pass → calcula ŷ
    loss   = criterio(y_pred, y_batch)  # 3. Calcular pérdida L(ŷ, y)

    loss.backward()                  # 4. Backprop → calcula ∂L/∂w para cada w

    # Opcional: clip gradientes para evitar explosión
    nn.utils.clip_grad_norm_(modelo.parameters(), max_norm=1.0)

    optimizer.step()                 # 5. Actualizar: w ← w − η·∂L/∂w

    # Inspeccionar gradientes de un peso específico
    for name, param in modelo.named_parameters():
        if param.grad is not None:
            grad_norm = param.grad.norm().item()
            # grad_norm muy grande → considerar gradient clipping
            # grad_norm ≈ 0 → posible gradiente desvaneciente
⚠️

El orden zero_grad → forward → loss → backward → step es inviolable en PyTorch. Invertir cualquier paso produce resultados incorrectos sin mensaje de error. El error más común es olvidar zero_grad(), haciendo que los gradientes se acumulen entre batches.

Inicialización de pesos — por qué importa

❌ Inicialización en cero

Todas las neuronas de una capa producen la misma salida → reciben el mismo gradiente → aprenden lo mismo. La capa entera actúa como una sola neurona. Nunca hacer esto.

✅ Xavier / He initialization

Xavier (para tanh/sigmoide): w ~ N(0, √(2/(n_in+n_out))). He (para ReLU): w ~ N(0, √(2/n_in)). PyTorch las aplica automáticamente por defecto al crear capas nn.Linear.

Optimizadores

El optimizador define la regla exacta de actualización de los pesos usando los gradientes calculados por backprop. La elección del optimizador y la tasa de aprendizaje (η) son de los hiperparámetros más importantes.

SGD — Descenso del gradiente estocástico

w ← w − η·∂L/∂w

El más simple. Actualiza los pesos una vez por batch. Con momentum: acumula gradientes en la dirección correcta y suaviza las oscilaciones. Estable pero lento al converger.

Adam — Adaptive Moment Estimation

m = β₁·m + (1−β₁)·g
v = β₂·v + (1−β₂)·g²
w ← w − η·m̂/√v̂

Mantiene una media móvil del gradiente (m) y su cuadrado (v). Adapta la tasa de aprendizaje por parámetro. El más usado en la práctica. β₁=0.9, β₂=0.999 por defecto.

AdamW

Adam + regularización L2 aplicada directamente a los pesos (weight decay desacoplado). Mejor generalización que Adam estándar. Recomendado para la mayoría de tareas QSAR.

Learning Rate Scheduler

Reducir η durante el entrenamiento mejora la convergencia. Opciones: CosineAnnealingLR, ReduceLROnPlateau (reduce lr cuando la validación deja de mejorar), OneCycleLR.

💡

El learning rate es el hiperparámetro más crítico. Demasiado grande: el entrenamiento oscila y diverge. Demasiado pequeño: converge muy lentamente o queda atrapado en mínimos locales. Valor típico inicial: 1e-3 con Adam.

# Configuración típica para clasificación QSAR
optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=1e-3,
    weight_decay=1e-4   # regularización L2
)

scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(
    optimizer,
    mode='min',          # minimizar val_loss
    factor=0.5,          # reducir lr a la mitad
    patience=5,          # esperar 5 épocas sin mejora
)

for epoch in range(N_EPOCHS):
    val_loss = train_one_epoch(...)
    scheduler.step(val_loss)  # actualizar lr

Regularización y sobreajuste

Las redes neuronales tienen millones de parámetros y pueden memorizar perfectamente el training set — produciendo pérdida ≈ 0 en train pero fallando completamente en datos nuevos. La regularización previene esto forzando al modelo a aprender patrones generalizables.

Underfitting

El modelo es demasiado simple o poco entrenado. Error alto tanto en train como en test. Solución: más capacidad (capas, neuronas), más épocas, menos regularización.

Overfitting

El modelo memoriza el training set. Error muy bajo en train, alto en test. Brecha creciente entre las curvas de loss. Solución: regularización.

Generalización correcta

Curvas de loss de train y test paralelas y cercanas. El modelo aprendió patrones reales, no ruido. Objetivo del entrenamiento.

Técnicas de regularización

Dropout

Durante cada forward pass del entrenamiento, cada neurona se "desactiva" con probabilidad p (típico: 0.2–0.5). Fuerza a la red a aprender representaciones redundantes — no puede depender de ninguna neurona individual. Se desactiva durante la evaluación.

nn.Dropout(p=0.3)  # 30% prob

Regularización L2 (Weight Decay)

Añade λ·Σwᵢ² a la función de pérdida. Penaliza pesos grandes — el modelo prefiere soluciones con pesos pequeños y distribuidos. En AdamW se aplica directamente sobre los pesos, no sobre el gradiente.

AdamW(weight_decay=1e-4)

Early Stopping

Monitoriza la pérdida en un validation set. Si no mejora después de N épocas (patience), detiene el entrenamiento y restaura los pesos del mejor epoch. El validation set debe ser independiente del test set.

if val_loss < best_loss:
    best_loss = val_loss
    save(model)  # guardar

Batch Normalization

Normaliza las activaciones de cada capa a media 0 y varianza 1 dentro del batch. Estabiliza el entrenamiento, permite learning rates más altos, y actúa como regularizador suave. Va entre la capa lineal y la activación.

nn.Linear(256, 128),
nn.BatchNorm1d(128),
nn.ReLU(),

Implementación en PyTorch

PyTorch define redes neuronales como clases Python que heredan de nn.Module. Cada capa es un objeto con parámetros aprendibles. El autograd construye el grafo computacional durante el forward pass y lo usa para backpropagación automática.

Definición de la arquitectura

import torch
import torch.nn as nn

class RedQSAR(nn.Module):
    def __init__(self, n_features, n_hidden=[256,128,64], dropout=0.3):
        super().__init__()
        capas = []
        prev = n_features
        for n in n_hidden:
            capas += [
                nn.Linear(prev, n),     # capa lineal: y = xW + b
                nn.BatchNorm1d(n),      # normalización de batch
                nn.ReLU(),              # activación no lineal
                nn.Dropout(dropout),   # regularización
            ]
            prev = n
        capas.append(nn.Linear(prev, 1)) # capa de salida (logit)
        self.red = nn.Sequential(*capas)

    def forward(self, x):
        # BCEWithLogitsLoss aplica sigmoide internamente
        return self.red(x).squeeze(-1)

modelo = RedQSAR(n_features=300)
print(f"Parámetros: {sum(p.numel() for p in modelo.parameters()):,}")

Loop de entrenamiento completo

Redes neuronales en QSAR

Las redes neuronales se aplican en QSAR cuando los patrones que relacionan estructura y actividad son demasiado complejos para modelos lineales o cuando el dataset es suficientemente grande para que la capacidad adicional sea beneficiosa.

¿Cuándo usar redes vs modelos clásicos?

Tamaño del dataset≥ 500 moléculas≥ 5 000 recomendado

Escalado requeridoNoSí — StandardScaler obligatorio

Tiempo entrenamiento1–5 min10 min–horas (GPU acelera 10–100×)

Regla práctica: empieza siempre con Random Forest o XGBoost. Si supera AUC 0.90 con validación cruzada robusta, una red neuronal difícilmente lo mejorará de forma significativa. Usa redes cuando tienes >10 000 moléculas, datos heterogéneos (multi-modal), o quieres aprender directamente desde la estructura del grafo molecular.

Consideraciones específicas para QSAR

Desbalance de clases

En QSAR con umbral ≥ 8 (pIC50), los activos son el 10–20% del dataset. Usar BCEWithLogitsLoss(pos_weight=ratio) o SMOTE solo sobre el training set. El Y-scrambling es especialmente importante para detectar data leakage.

Escalado de features

Los descriptores Mordred tienen escalas muy distintas (MW ≈ 300, TPSA ≈ 60, HBD ≈ 3). Sin StandardScaler, los pesos de la primera capa serán dominados por los features de mayor escala. Ajustar el scaler solo sobre X_train.

Fingerprints binarios

Morgan ECFP4 (2048 bits) es muy disperso — el 95%+ de los bits son 0. Para redes, considerar reducir dimensión con PCA antes, o usar Embedding inicial que convierta los bits en vectores densos.

Dominio de aplicabilidad

En redes neuronales, el DA se puede estimar con la incertidumbre de predicción usando Monte Carlo Dropout: activar dropout en inferencia y hacer N predicciones. La varianza entre predicciones indica la incertidumbre.

Graph Neural Networks (GNN)

Las GNNs representan el estado del arte en predicción molecular porque procesan directamente el grafo molecular — sin necesidad de calcular descriptores ni fingerprints. La molécula es el grafo: átomos = nodos, enlaces = aristas.

h_v^(l+1) = σ(W · AGGREGATE({h_u^(l) : u ∈ N(v)}) + b) h_v = embedding del átomo v · N(v) = vecinos de v · l = número de capa de message passing

En cada capa de message passing, cada átomo agrega la información de sus vecinos inmediatos. Después de L capas, cada átomo tiene un embedding que captura el contexto a L enlaces de distancia — análogo al radio en los fingerprints de Morgan.

Ventajas sobre fingerprints tradicionales

Aprendizaje end-to-end

La red aprende qué información estructural es relevante para el target específico — no depende de descriptores calculados manualmente.

Información estereoquímica

Puede incorporar quiralidad, geometría 3D y otras propiedades que los fingerprints clásicos no capturan bien.

Multi-tarea

Un modelo GNN puede predecir múltiples propiedades (ADMET, toxicidad, actividad) simultáneamente desde la misma representación molecular.

Librerías disponibles

PyTorch Geometric

La más completa. Implementa GCN, GAT, MPNN, DimeNet++, SchNet. Gran comunidad y documentación.

DGL

Deep Graph Library. Multi-backend (PyTorch / TensorFlow). Muy eficiente para grafos grandes.

DeepChem

Enfocado en química y biología computacional. Integra GNNs + datasets moleculares estándar + splits por scaffold.

from torch_geometric.nn import GCNConv, global_mean_pool
from torch_geometric.data import Data

class GCN_QSAR(nn.Module):
    def __init__(self, n_node_features, n_hidden=128):
        super().__init__()
        # Capas de message passing
        self.conv1 = GCNConv(n_node_features, n_hidden)
        self.conv2 = GCNConv(n_hidden, n_hidden)
        self.conv3 = GCNConv(n_hidden, n_hidden)
        # Clasificador final
        self.cls = nn.Linear(n_hidden, 1)

    def forward(self, x, edge_index, batch):
        # Message passing sobre el grafo molecular
        h = nn.functional.relu(self.conv1(x, edge_index))
        h = nn.functional.relu(self.conv2(h, edge_index))
        h = self.conv3(h, edge_index)
        # Readout: agregar nodos → representación de la molécula
        h = global_mean_pool(h, batch)
        return self.cls(h).squeeze(-1)
